# 版本日志

本文件用于记录《鼠鼠大王工具箱》各发行版的功能概要，每个版本一节，按发布时间倒序排列。

## Beta-3.0（2026-10-02）

**当前版本**：新增「改枪码・主播推荐」工具，从 shushu.fan 全量同步主播改枪方案，卡片化筛选与翻页浏览。

### 改枪码（鼠鼠工具分组 → 改枪码二级分组）

- 新增二级侧栏分组「改枪码」，内含「主播推荐」标签页（一级/二级分组字号区分，默认收起）
- 数据源：shushu.fan 公开分页 API（/api/guns-code/official），全量同步主播推荐方案（首次实测 1027 条，共 1268 条方案中过滤官方裸方案）
- 自动同步：启动与驻留周期检查，按配置间隔拉取（默认 10 天）；失败进入 6 小时冷却；无手动刷新按钮（第三方服务器压力友好）
- 卡片展示：预览图 + 枪械名/类型 + 作者头像与平台徽标 + 评语滚动区（独立滚动、格式统一）+ 标签 + 价格/点赞 + 一键复制改枪码
- 四维筛选：武器类型 / 枪械名称 / 作者 / 标签，本地即时过滤；武器类型变化联动枪械选项
- 翻页渲染：默认每页 20 张（配置 gun_render_page_size），任何时刻只实例化当前页，内存峰值固定单页；末页不足/页数变化自动兼容
- 图片三层缓存：磁盘 data/gun_images/（存在即跳过下载、原子写）+ QPixmapCache 内存 LRU（默认 64MB，配置 image_cache_limit_mb）+ 当前页懒加载
- 数据去重：以方案 id 幂等（跨页合并首条保留 + 缓存整体替换快照），缓存天然无重复，已下架方案随下次同步自动消失
- 配置项（仅配置文件修改，不进设置界面）：gun_sync_interval_days / image_cache_limit_mb / gun_render_page_size

### 技术说明

- 改枪码模块含同步/解析/去重/缓存/翻页/图片缓存等 40+ 项测试；全量测试 147 项通过

## Beta-2.0（2026-10-02）

**当前版本**：新增「每日密码」工具，多源获取、缓存优先、卡片化展示。

### 每日密码（鼠鼠工具分组）

- 新增一级侧栏分组「鼠鼠工具」，内含「每日密码」标签页
- 每日六地图密码：零号大坝 / 长弓溪谷 / 巴克什 / 航天基地 / 潮汐监狱 / AZ3，卡片显示顺序固定、跨源稳定
- 多数据源拉取与优先级：tmini 免费接口为主源、shushu.fan 为备用，主源失败自动回退；来源优先级可在设置页修改，实时同步（下次刷新生效）
- 缓存与限频友好：按日缓存（`data/daily_password_cache.json`），当日直接渲染不重复请求；跨日自动刷新；全部来源失败回退旧缓存并节流 15 分钟，防打满上游限频
- 卡片展示：地图缩略图 + 名称 + 密码 + 位置描述；卡片宽度随窗口自适应填满每行（流式网格，列数单调、平滑调整不闪烁）；描述区独立滚动
- 位置描述内置本地资源兜底（不依赖数据源提供）；「AZ3核电站」等源命名自动归一为「AZ3」
- 大图预览：点击卡片弹出悬浮窗显示大图，预览打开期间点击其他卡片为替换模式（同一窗口），点击窗口任意位置关闭
- 页面完全适配明暗双主题

### 技术说明

- 每日密码模块含数据源解析、优先级回退、缓存、节流、卡片布局、大图预览等 26+ 项测试；全量测试 95 项通过

## Beta-1.1（2026-10-01）

**当前版本**：拼图体验与性能改进版。

### 骇爪美图（拼图小游戏）

- 碎片数量一致化：网格按目标碎片数求解（默认 48 块），不同图片宽高比下碎片数稳定，难度体验统一
- 新增配置项 `puzzle_pieces`：可自定义开局碎片数量（4–200），仅通过 `data/settings.json` 配置文件修改，不在设置界面显示
- 性能改进：
  - 完成判定改为增量维护（已吸附集合 O(1)），不再每次释放全量扫描
  - 圆弧自适应采样：按 view 缩放与设备像素比动态决定折线密度，像素级平滑同时路径点数减少约 17 倍

### 修复

- 修复持久化写回覆盖用户在配置文件中手改字段的问题（写回前先读回合并）

## Beta-1.0（2026-10-01）

**当前版本**：首次发行版，桌面工具集雏形，内置"骇爪美图"拼图游戏。

### 骇爪美图（拼图小游戏）

- 拼图玩法：随机选图开局，碎片随机打散旋转，拖拽吸附归位，全部归位即完成
- 拼图边缘：尖角凸凹与半圆凸随机混合，曲线平滑渲染
- 计时器：第一次拿起碎片开始计时，完成后停止，重新开局自动重置
- 最佳成绩：按图片文件名持久化记录最快完成用时，仅更短用时才更新
- 图片来源与作者窗口：
  - 图片卡片网格展示（缩略图 + 作者 + URL），缩略图磁盘缓存加速打开
  - URL 可点击，自动在浏览器打开
  - 卡片底部显示该图最快完成用时
  - 底部"打开文件位置"按钮，直接打开图片所在文件夹
  - 非模态窗口，不阻塞主窗口

### 界面与框架

- 侧边栏：可拖拽调整宽度（160–420px），支持分组折叠展开
- 导航结构：首页 / 牢区小游戏分组（含骇爪美图）/ 设置
- 首页：展示作者信息（PastSheep | wzylscszyzh@163.com，邮箱可点击）
- 设置：主题切换（暗色/浅色）、语言设置（当前仅中文），重启后保持
- 明暗主题全面适配：窗口、侧栏、设置页、来源窗口、滚动条均随主题变化
- Windows 标题栏：跟随应用主题实时变色，标题文字隐藏（仅侧栏顶部显示品牌名）
- 应用图标：鼠鼠表情包多尺寸 ICO（16–256px）
- 全局交互细节：下拉框无箭头、滚动条自定义样式

### 技术说明

- Python 3.12 + PySide6（Qt6），Windows 桌面应用
- 设置与成绩数据持久化于 `data/`（运行时生成，不入库）
- 45 项自动化测试覆盖核心功能，全部通过

### 修复

- 修复「打开文件位置」按钮在含空格安装路径（如 Program Files）下打开错误文件夹的问题（2026-10-01）
