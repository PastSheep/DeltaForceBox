## Beta-4.2（2026-10-02）

**当前版本**：我的改枪码添加/编辑时，枪械名称与武器类型由改枪码自动解析带出，无需手动输入。

### 我的改枪码（鼠鼠工具 → 改枪码）

- 枪械名称与武器类型存在从属关系（枪械名称可从改枪码首段解析、武器类型按枪械查缓存映射），因此添加/编辑表单不再提供枪械名称、武器类型输入项，改为自动带出的只读展示
- 改枪码输入时实时解析：枪械名称 = 改枪码首段；武器类型 = 缓存从属映射（gun_name → weapon_type）
- 未命中映射（新枪 / 自定义码）：枪械名称仍带出（改枪码首段），武器类型留空，卡片照常显示「枪械名称」（类型为空时不显示分隔符）
- 编辑旧记录同样自动带出；保存时以自动解析结果落盘（weapon / weapon_type）

### 技术说明

- 新增 `core/my_codes.py::build_gun_weapon_map`（从改枪码缓存构建枪械→类型从属映射）；表单两个可编辑下拉改为只读 QLineEdit，改枪码 `textChanged` 驱动 `_auto_fill_meta`
- 新增 4 项测试（映射构建 / 实时带出 / 只读校验 / 自动落盘），全量测试 209 项通过

## Beta-4.1（2026-10-02）

**当前版本**：筛选下拉升级为可输入搜索（主播推荐 / 我的改枪码同步），我的改枪码补齐描述占位、筛选提示与红色删除。

### 筛选框可输入（主播推荐 + 我的改枪码）

- 所有筛选下拉在保持下拉候选之外新增输入功能：可输入任意文本，输入时弹层候选即时按输入过滤（包含匹配、大小写不敏感）
- 输入文本即筛选：无需点选候选，输入即按「包含匹配」过滤（枪械 / 武器类型 / 作者 / 标签四维 AND）
- 点击筛选框（输入框区域）：清空输入并展开全量候选，便于直接输入或点选；输入框获得焦点同样展开全量候选
- 无条件两种表达：空白输入，或点选候选顶部「全部」文本项（内部一律视为无条件）；「全部重置」后恢复无条件
- 非焦点且无筛选条件时，输入框显示「全部」提示文本，便于理解当前为无条件；失焦后自动恢复该提示
- 输入任意文本不会固化进候选列表；武器类型联动收窄枪械候选时保留当前枪械输入（输入不丢失）

### 我的改枪码

- 未填写描述时卡片显示「暂无详细介绍」（有描述仍显示原文）
- 筛选框补齐文字提示：「枪械名称」「武器类型」标签
- 卡片删除按钮改为红色样式（双主题适配）

### 技术说明

- 新增 `widgets/search_combo.py`（SearchCombo：editable + NoInsert + QCompleter 包含匹配 + 事件过滤器拦截输入框点击 / 焦点变化 + set_items 保留输入 / filter_text / reset）
- 主播推荐页 `_apply_filters` / `_render_filtered` 统一走 `_match_solution` 包含匹配
- 新增 16 项测试（点击弹层 / 焦点弹层 / 失焦提示 / 输入过滤 / 不固化候选 / 联动收窄 / 描述占位 / 红色删除 / 筛选提示），全量测试 205 项通过
