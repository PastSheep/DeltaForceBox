## Beta-5.4（2026-10-04）

**当前版本**：四项加固收尾（线程退出硬崩溃 / 类型防御 / 缓存归一化 / 启动提速），后台线程退出统一加固，杜绝进程退出 0xC0000409 崩溃。

### 修复

- **每日密码请求进行中关闭窗口仍硬崩溃**（A 残留缺口）：`_FetchWorker` 注册表持有（防页面回收析构运行中线程）+ `_shutdown` 等待上限提至 `FETCH_TIMEOUT+2s`；实证复现脚本退出码由 -1073740791 归 0
- **safe_int 对 bool 误转**（B）：`isinstance(value, bool)` 直接回退默认，True/False 不再被 `int()` 转成 1/0
- **缓存反序列化 id 不校验**（C）：`_solution_from_dict` 对 id 显式 `_to_int`，非法/缺失跳过该条，author_id 归一 0，杜绝异常 id 缓存文件名
- **拼图选图主线程全量解码**（D）：`pick_random_image` 改`QImageReader.canRead()+size()` 头部探测，启动提速
- **改枪码图片/同步线程退出加固**：`_shutdown` 等待上限提至 `FETCH_TIMEOUT+2s`（15s 请求超时 + 余量），与注册表组合，实证脚本退出码 0
- **行尾规范化**：gun_code_page import 区裸 CR 挤压行、my_codes_page / test_updater残留 CR 行尾统一转 LF（入库形式），清除 CRLF 双重污染根源

### 文档

- 踩坑记录：补「注册表仅防页面回收、进程退出须组合等待上限」实证结论；新增「补丁脚本行尾污染两度重犯」条目
- 开发规范：`_shutdown` 等待上限规则与行尾纪律补入

### 验证

- 新增 3 项防回归测试（worker 注册/移除、safe_int bool、id 归一化）；全量测试 247 项通过，ruff 通过
- 退出崩溃实证脚本保留于 .tmp/（verify_residual_crash_fixed.py / verify_gun_shutdown_fixed.py）可复核

## Beta-5.2（2026-10-04）

**当前版本**：依据《Beta5.1全量检查报告》15 项逐一验证并修复（高危 3 / 中危 4 / 低危 8），加固崩溃面与数据健壮性。

### 修复

- **#1（高危）每日密码拉取线程退出未收尾 → 硬崩溃**：`fetch_password` 新增 `should_stop` 回调，`_FetchWorker.run` 传 `isInterruptionRequested`；每日密码页新增 `_shutdown()`（requestInterruption + wait 限时等待），由 `MainWindow.closeEvent` 统一遍历调用。复现：关闭窗口瞬间线程仍在跑 → 0xC0000409 fail-fast，修复后线程快速退出
- **#2（高危）隐藏配置非法值启动崩溃**：新增 `core/settings.safe_int(value, default, lo, hi)`（非数字回退默认、越界 clamp）；`app.py` 四个整型隐藏配置（puzzle_pieces / gun_sync_interval_days / gun_render_page_size / image_cache_limit_mb）与 `updater.py` 的 `update_timeout_s` / Release 资产 `size` 全部改走 `safe_int`，用户手改任意内容不再导致启动崩溃
- **#3（高危）拼图损坏图除零崩溃**：`pick_random_image` 增加解码探测（`QImage` isNull / 零尺寸跳过），`start_new` 对零尺寸兜底抛 `ValueError` 并显示加载失败；垃圾字节 png 不再使启动崩溃
- **#4（中危）作者昵称含 Windows 非法字符 → 头像下载永久失败**：`avatar_image_path` 新增 `_safe_filename`（`<>:"/\|?*` 与控制字符替换为 `_`、去尾随点/空白、空串回退 `unknown`），不再写盘失败或落入嵌套子目录
- **#5（中危）改枪码图片下载线程竞态**：`_ensure_images` 串行化——worker 运行中到达的新任务并入待办、结束后再启动；`finished` 回调校验 `self._image_worker is worker` 后再置空；`_shutdown` 置 `_closing` 标志，关闭后不再启动新 worker，杜绝多 worker 并发写同一 `.tmp` 路径
- **#6（中危）打包元数据滞后**：`scripts/version_info.txt`（Beta-5.0 → Beta-5.2，filevers/prodvers 0,5,0,0 → 0,5,2,0）与 `scripts/installer.iss`（MyAppVersion 5.0.0 → 5.2.0、OutputBaseFilename / VersionInfoVersion 同步）随本版更新
- **#7（中危）`_parse_solution_obj` 对 armsID/id 非数字无防护**：新增 `_to_int` 宽容转换，单条异常不再拖垮整次同步
- **#8（低危）`normalize_source_order` 类型防护**：非列表/元组（如手改成整数）回退默认顺序，不抛 TypeError
- **#9（低危）start.bat 乱码**：GBK → UTF-8 带 BOM，cmd 下中文正常显示
- **#10（低危）i18n 死键**：删除无代码引用的 4 个 key（guncode.page_info / puzzle.sources.file / puzzle.sources.url / common.ok）
- **#11（低危）重复 spec**：`DeltaForceBox.spec` 与 `鼠鼠大王工具箱.spec` 内容完全相同且构建脚本不引用任何 spec，删除英文名冗余文件（均已被 .gitignore 忽略）
- **#13（低危）更新器未过滤 draft/prerelease**：`fetch_latest_release` 跳过草稿/预发布 Release（tag 可能高于正式发布），资产 `size` 非数字回退 0
- **#14（低危）我的改枪码卡片删除方式**：`_render` 由 `deleteLater` 改为 `shiboken6.delete` 立即删除，与主播推荐页及开发规范一致，消除退出时双重删除风险
- **#15（低危）缓存反序列化脆弱**：`_apply_cache` 改为字段白名单逐条构造（`_solution_from_dict`），旧缓存多/缺字段只跳过该条，不再整页空白

### 验证

- 报告中 #12（受保护目录 data/ 写入静默失败）经实测不属实（data/ 可正常写入、无只读属性），未实施修改
- 新增 8 项防回归测试：`fetch_password` should_stop、`normalize_source_order` 类型防护、拼图损坏图跳过、头像文件名安全化、`_parse_solution_obj` 非数字 id、`safe_int` 归一化、更新器过滤 draft/prerelease、资产 size 非数字
- 全量测试 244 项通过，ruff 通过

### 技术说明

- 开发规范同步补充：页面级线程 `_shutdown()` 约定、下载线程串行化、整型配置统一 `safe_int`、缓存白名单反序列化、外部输入作文件名的 sanitize、更新器过滤 draft/prerelease

**当前版本**：自动更新功能；仓库转公开（PolyForm Noncommercial 1.0.0 非商用许可）。

### 自动更新

- 启动时检查 GitHub Releases（设置界面四选一：自动更新 / 下载但不自动安装 / 新版本提示 / 关闭，默认自动更新）
- 版本比较：Beta-X.Y（预发布）< v-X.Y（正式版），正式版前缀切换无需迁移；按语义版本取远端最高 Release（不依赖 GitHub latest 语义），每个定版需创建 Release 才会被发现

- 首页右上角内嵌提示条（非弹窗，双主题适配）承载更新提示：发现新版本 / 下载进度 / 更新就绪 / 失败重试 / 打开安装包位置
- 自动更新模式：下载完成写 `data/pending_update.json`，退出程序时静默拉起安装器（`/VERYSILENT`），拉起成功即清空待安装状态、失败保留下次启动自愈；本地已是最新时自动清理残留 pending（防重复重装）
- 仓库转公开：PolyForm Noncommercial License 1.0.0（非商用，商用须书面授权）；README / pyproject 同步标注

- 新增 `core/updater.py`（纯逻辑无 Qt）：`parse_version` / `fetch_latest_release` / `download_asset`（断点续传）/ pending 状态读写
- 新增 `widgets/update_controller.py`（后台线程检查下载 + Qt 信号驱动 UI）、`widgets/notice_bar.py`（右上角提示条组件）
- 隐藏配置新增：`update_mirrors` / `update_timeout_s`（`resources/config/app_config.json`）

### 我的改枪码（鼠鼠工具 → 改枪码）

- 枪械名称与武器类型存在从属关系（枪械名称可从改枪码首段解析、武器类型按枪械查缓存映射），因此添加/编辑表单不再提供枪械名称、武器类型输入项，改为自动带出的只读展示

- 未命中映射（新枪 / 自定义码）：枪械名称仍带出（改枪码首段），武器类型留空，卡片照常显示「枪械名称」（类型为空时不显示分隔符）
- 编辑旧记录同样自动带出；保存时以自动解析结果落盘（weapon / weapon_type）

### 技术说明

- 新增 `core/my_codes.py::build_gun_weapon_map`（从改枪码缓存构建枪械→类型从属映射）；表单两个可编辑下拉改为只读 QLineEdit，改枪码 `textChanged` 驱动 `_auto_fill_meta`
